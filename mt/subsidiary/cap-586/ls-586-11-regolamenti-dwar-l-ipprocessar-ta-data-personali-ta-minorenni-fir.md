# Regolamenti dwar l-Ipproċessar ta’ Data Personali ta’ Minorenni fir-rigward tal-Offerta ta’ Servizzi minn Soċjetà tal-Informazzjoni (S.L. 586.11)

**LEĠISLAZZJONI SUSSIDJARJA 586.11**

REGOLAMENTI DWAR L-IPPROĊESSAR TA’ DATA PERSONALI TA’ MINORENNI FIR-RIGWARD TAL-

**OFFERTA TA’ SERVIZZI MINN SOĊJETÀ TAL-**

**INFORMAZZJONI**

1 ta’ Ġunju, 2018

L-AVVIŻ LEGALI 179 tal-2018.

## 1. Titolu.

It-titolu ta’ dawn ir-regolamenti huwa r-Regolamenti dwar l-Ipproċessar ta’ Data Personali ta’ Minorenni fir-rigward tal- Offerta ta’ Servizzi minn Soċjetà tal-Informazzjoni.

## 2. Tifsir.

F’dawn ir-regolamenti, sakemm ir-rabta tal-kliem ma teħtieġx xort’oħra:

*Kap. 586*

"Att" tfisser l-Att dwar il-Protezzjoni u l-Privatezza tad-Data;

"ir-Regolament" għandu jkollha l-istess tifsira kif mogħtija lilha fl-artikolu 3 tal-Att.

(2) L-artikolu 3(2) tal-Att għandu japplika mutatis mutandis għal dawn ir-regolamenti.

## 3. Kamp ta’ applikazzjoni.

Il-kamp ta’ applikazzjoni u l-għan ta’ dawn ir-regolamenti hu li tiġi stabbilita l-età ta’ minorenni meta tkun qed tiġi pproċessata data personali fil-kuntest ta’ servizzi minn soċjetà tal-informazzjoni fl-assenza ta’ kunsens mid-detentur tar-responsabbilità ta’ ġenitur fuq il-minorenni konformement mal-Artikolu 8 tar- Regolament.

## 4. Ipproċessar ta’ data personali ta’ minorenni.

L-ipproċessar ta’ data personali ta’ minorenni fir-rigward ta’ servizzi minn soċjetà tal-informazzjoni jkun legali meta l-minorenni jkollu tlettax-il sena.
